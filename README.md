## 📦 Installation

1. Download the latest release of **Skin3D**.
2. Place the plugin `.phar` file inside your PocketMine-MP `plugins` directory.
3. Restart your PocketMine-MP server.
4. Configure the plugin if required.

---

## 📋 Requirements

* **PocketMine-MP**
* **Minecraft: Bedrock Edition**
* **PHP** version compatible with your PocketMine-MP version
